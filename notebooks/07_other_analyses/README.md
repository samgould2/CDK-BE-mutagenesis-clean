# 07 — other analyses

Nothing runs here. These analyses ship as tables and are drawn from them:

* splicing — `data/processed/splicing/` (SpliceAI scores)
* variant effect — `data/reference/alphamissense/`, `data/reference/gnomAD/`
* clinical resistance — `data/reference/resistance_databases/` (OncoKB, CIViC)
* predicted CDK9-ligand complexes — `data/raw/cdk9_boltz/`, drawn by
  `cdkbe.source_data.cdk9_boltz`

`docs/METHODS.md` describes each.
