# 05 — bulk RNA-seq

Nothing runs here. The DESeq2 results, TPM matrices and GSEA tables for the
PC3, LNCaP and T47D experiments ship under `data/processed/rnaseq/`, together
with the collaborators' own analysis notes, and `cdkbe.source_data.rnaseq`,
`rnaseq_t47d` and `rnaseq_volcanoes` draw the panels from them.

The DESeq2 and GSEA runs themselves are upstream of this repository.
`docs/METHODS.md` §5 says what each contrast is.
